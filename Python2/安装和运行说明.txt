PM2.5预测与静稳天气分析 - 安装和运行说明
====================================

一、环境要求
------------------------------------
- Python 3.8+ 版本
- 所需Python包:
  * pandas
  * numpy
  * scikit-learn
  * matplotlib
  * seaborn
  * xgboost
  * lightgbm
  * joblib
  * tqdm

二、安装方法
------------------------------------
1. 确保已安装Python 3.8+版本
2. 安装所需依赖包：

```bash
pip install pandas numpy scikit-learn matplotlib seaborn xgboost lightgbm joblib tqdm
```

三、运行方法
------------------------------------
1. 完整流程运行:

```bash
python main.py
```

2. 选择性运行部分流程:

```bash
# 跳过数据加载步骤
python main.py --skip-data-loading

# 跳过特征工程步骤
python main.py --skip-feature-engineering

# 跳过模型训练步骤
python main.py --skip-model-training
```

3. 单独运行某一模块:

```bash
# 数据加载与预处理
python data_loader.py

# 特征工程
python feature_engineering.py

# 模型训练与评估
python model_training.py

# 模型改进
python model_improvement.py
```

四、目录结构说明
------------------------------------
- Python2/: 代码目录
  * data_loader.py: 数据加载与预处理模块
  * feature_engineering.py: 特征工程模块
  * model_training.py: 模型训练与评估模块
  * model_improvement.py: 模型改进模块
  * main.py: 主程序入口

- processed2/: 处理结果目录，程序运行会自动创建
  * train_data.csv: 训练数据
  * test_data.csv: 测试数据
  * processed_train.csv: 特征工程后的训练数据
  * processed_test.csv: 特征工程后的测试数据
  * figures/: 图表目录
  * models/: 模型保存目录

五、注意事项
------------------------------------
1. 确保原始数据集位于 ../processed/processed_data.csv
2. 首次运行会自动创建 processed2 目录及其子目录
3. 如提示某模块找不到，请检查是否已安装所有依赖
4. 完整运行可能需要较长时间，尤其是特征工程和模型训练步骤

六、结果查看
------------------------------------
运行完成后，可在 processed2 目录下查看：
1. conclusion_report.txt: 模型性能结论报告
2. model_improvement_report.txt: 模型改进报告
3. figures/ 目录下的各类可视化图表
4. models/ 目录下保存的模型文件
