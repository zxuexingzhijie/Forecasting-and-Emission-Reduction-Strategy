# 基于空气质量数据的预测与减排策略优化

## 摘要

大气污染特别是PM2.5污染已成为影响人类健康和环境质量的重要问题。精确预测PM2.5浓度并制定有效的减排策略对于空气质量管理和污染防控具有重大意义。我国北方地区冬季易出现高浓度PM2.5污染，而静稳天气条件下污染物扩散受限，更容易形成污染累积，因此研究静稳天气下的PM2.5预测准确性和减排措施优化尤为重要。

本研究旨在通过对空气质量数据的深入分析和建模，实现准确的PM2.5浓度预测，并在此基础上优化减排策略，为空气质量改善提供科学依据和决策支持。

**问题一**：对数据进行预处理与时空特征分析。研究发现PM2.5浓度呈现明显的季节性变化，冬季高于平均水平63%，夏季低于平均水平37%；日内变化呈双峰模式，早晨和傍晚峰值分别高于日均值18%和25%；风速是影响PM2.5最显著的气象因素，相关系数为-0.397，静稳天气下PM2.5浓度高于非静稳天气63.5%。

**问题二**：构建PM2.5预测模型并分析静稳天气下性能。对比多种机器学习模型，LightGBM表现最佳，测试集RMSE为17.85μg/m³，R²为0.91；静稳天气下模型性能有所下降，RMSE增加6.41%，MAE增加18.16%；提出专门化建模策略后，静稳天气下的预测误差显著降低，RMSE减少11.7%，MAE减少12.4%。

**问题三**：优化减排策略以达到目标浓度。通过整数规划模型，在目标减排量为18.69μg/m³的情况下，得到最优方案：实施10小时洒水抑尘，总成本30,000元，远低于预算上限100,000元；从成本效益比分析，洒水抑尘最经济（6.67μg/m³/万元），其次是工厂限产（6.25μg/m³/万元）和限行（6.00μg/m³/万元）。

研究成果不仅验证了模型方法的有效性，也为空气质量管理提供了科学决策支持。

**关键词**：PM2.5预测，静稳天气，减排优化，LightGBM，整数规划


## 2. 问题重述与模型假设

### 2.1 问题重述

本研究针对北京东四站点2013年3月1日至2017年2月28日的空气质量监测数据，解决以下三个问题：

**问题一**：进行数据预处理与时空特征分析，探究PM2.5浓度的时间变化规律与气象因素的关系。

**问题二**：以东四站点PM2.5为目标变量，构建预测模型，使用2013-2015年数据训练，2016年数据测试，分析预测模型在静稳天气（风速<1m/s）下的预测误差是否显著增大，提出改进策略。

**问题三**：基于问题二构建的PM2.5预测模型，给出指定日期的PM2.5日均浓度预测值，并探索如何通过三种减排措施（限行、工厂限产、洒水抑尘）将当日PM2.5浓度降至预测值的80%，在总预算10万元/日的约束下，确定各措施在6:00-22:00时段内的最优实施时长，使总成本最低。

### 2.2 模型假设

为了简化问题并使模型更加可行，本研究做出以下假设：

1. **数据代表性假设**：东四站点的监测数据能够代表其周边区域的空气质量状况，站点测量的污染物浓度与气象参数准确反映了实际情况。

2. **数据平稳性假设**：污染物浓度的时间序列在短期内（如日内、周内）具有一定的平稳性，可以通过历史数据进行预测。

3. **特征独立性假设**：建模过程中，认为各特征变量之间不存在严重的多重共线性问题，变量间的相关性不会显著影响模型性能。

4. **线性叠加假设**：在减排策略优化中，假设不同减排措施的效果可以线性叠加，各措施间不存在明显的协同或拮抗效应。

5. **时效性假设**：减排措施的效果在实施期间保持恒定，并且在实施结束后迅速消失，不存在长期累积效应。

6. **空间均匀性假设**：减排措施在整个研究区域内均匀生效，不考虑空间分布不均的情况。

7. **成本稳定性假设**：各减排措施的单位成本在研究期间保持不变，不受实施时长、时段和频率的影响。

## 3. 数据预处理与时空特征分析

### 3.1 数据预处理

#### 3.1.1 数据概述

本研究使用北京东四站点2013年3月1日至2017年2月28日期间的空气质量监测数据，包含空气质量参数（PM2.5、PM10、SO₂、NO₂、CO、O₃）和气象参数（温度、气压、露点温度、降水、风向、风速）。数据维度包括时间（年、月、日、小时）和空间（监测站点）。

数据基本情况：
- 时间跨度：4年（2013.03-2017.02）
- 时间粒度：小时级
- 预期记录数：$4 \times 365 \times 24 = 35040$ 条（实际可能存在缺失）
- 变量数量：18个（时间维度4个，污染物指标6个，气象指标6个，站点标识1个，序号1个）

#### 3.1.2 缺失值填充

通过对原始数据分析，发现各变量存在约10%-15%的缺失值，针对不同类型的变量采用了不同的填充策略：

1. **气象数据填充**：
   - 短期缺失采用线性插值：
   
   $$y_t = y_{t-1} + \frac{y_{t+k} - y_{t-1}}{k}(t - (t-1))$$
   
   其中，$y_t$表示缺失的时间点$t$处的值，$y_{t-1}$和$y_{t+k}$分别表示缺失时间点前后最近的非缺失值。
   
   - 长期缺失（超过24小时）采用同时段历史均值：
   
   $$y_{missing}(m,d,h) = \frac{1}{n} \sum_{year} y(year,m,d,h)$$
   
   其中，$(m,d,h)$表示月-日-小时的时间组合，$n$为历史同时段有效观测数。

2. **污染物数据填充**：
   - 利用相关性最高的其他污染物进行线性回归预测：
   
   $$y_{missing} = \alpha \times x_{correlated} + \beta$$
   
   其中，$\alpha$和$\beta$是从非缺失数据中通过最小二乘法确定的线性回归系数。

3. **风向处理**：
   - 风向是循环性变量，采用角度插值，避免跨越0°/360°边界的问题：
   
   $$\theta_{missing} = \theta_{t-1} + \frac{\min(|\theta_{t+k} - \theta_{t-1}|, 360 - |\theta_{t+k} - \theta_{t-1}|)}{k} \times \text{sign}$$
   
   其中，$\text{sign}$确定插值方向（顺时针或逆时针），选择角度最小的方向。

#### 3.1.3 异常值处理

采用两种主要方法检测异常值：

1. **基于Z-score的检测**：  
   将偏离均值超过3个标准差的值视为异常值：
   
   $$z_i = \frac{x_i - \mu}{\sigma}$$
   
   其中，$|z_i| > 3$时判定$x_i$为异常值。

2. **基于IQR的检测**：  
   将超出四分位距离1.5倍的值视为异常值：
   
   $$\text{lower\_bound} = Q_1 - 1.5 \times IQR$$
   $$\text{upper\_bound} = Q_3 + 1.5 \times IQR$$
   
   其中，$Q_1$和$Q_3$分别为第一和第三四分位数，$IQR = Q_3 - Q_1$为四分位距。

对检测到的异常值，采用截断法或均值/中位数替换进行处理。

#### 3.1.4 特征工程

为增强数据的表达能力，构建了以下新特征：

1. **时间特征**：
   - 星期几、周末标记、季节、供暖期标记
   - 周期性特征变换：使用三角函数变换捕捉时间的周期性
     - $\text{hour\_sin} = \sin(2\pi \times \frac{\text{hour}}{24})$
     - $\text{month\_sin} = \sin(2\pi \times \frac{\text{month}}{12})$

2. **气象特征**：
   - 静稳天气标记：$\text{is\_stagnant} = \mathbb{1}_{\text{WSPM} < 1.0}$
   - 静稳持续时间：记录静稳天气持续的小时数
   - 风向周期性：$\text{wd\_sin} = \sin(\frac{\pi}{180} \times \text{wd\_angle})$

3. **污染物比值特征**：
   - PM比值：$\text{PM\_ratio} = \frac{\text{PM2.5}}{\text{PM10}}$（反映细颗粒物在可吸入颗粒物中的占比）

4. **空气质量等级分类**：根据PM2.5浓度设定空气质量等级

## 4. PM2.5预测模型构建与静稳天气性能分析

### 4.1 数据准备与特征工程

#### 4.1.1 数据划分

根据时间顺序划分训练集和测试集：
- 训练集：2013年3月1日至2015年12月31日（共23,184条记录）
- 测试集：2016年1月1日至2016年12月31日（共6,786条记录）

为防止信息泄露，在训练集和测试集之间设置了10天的间隔期。

#### 4.1.2 特征构建

构建了四类特征，总共形成超过100个特征变量：

1. **时间特征**：通过周期性编码表示时间循环特性

   $$x_{sin} = \sin\left(\frac{2\pi \cdot x}{P}\right), \quad x_{cos} = \cos\left(\frac{2\pi \cdot x}{P}\right)$$

   其中，$x$ 为时间变量（小时、日、月等），$P$ 为对应周期。

2. **滞后特征**：捕捉时间依赖性

   $$PM_{2.5}(t-\tau)$$

   其中，$\tau$ 为滞后时间，设为 [1, 2, 3, 6, 12, 24, 48] 小时。

3. **滚动特征**：捕捉短期趋势

   $$PM_{2.5\_rolling\_mean}(t, w) = \frac{1}{w}\sum_{i=1}^{w} PM_{2.5}(t-i)$$
   
   $$PM_{2.5\_rolling\_std}(t, w) = \sqrt{\frac{1}{w}\sum_{i=1}^{w} (PM_{2.5}(t-i) - PM_{2.5\_rolling\_mean}(t, w))^2}$$

   其中，$w$ 为窗口大小，设为 [3, 6, 12, 24, 48] 小时。

4. **差分特征**：刻画变化率

   $$\Delta PM_{2.5}(t) = PM_{2.5}(t) - PM_{2.5}(t-1)$$
   
   $$\Delta^2 PM_{2.5}(t) = \Delta PM_{2.5}(t) - \Delta PM_{2.5}(t-1)$$

5. **气象与污染物交互特征**：

   $$\text{Temp\_Humi} = \text{TEMP} \times \text{HUMI}$$
   
   $$\text{Wind\_Pres} = \frac{\text{WSPM}}{\text{PRES}}$$

#### 4.1.3 特征选择与降维

为防止过拟合，使用了多种特征选择方法：

1. **特征重要性筛选**：使用基于树模型的特征重要性评分

   $$\text{Importance}(X_j) = \sum_{i=1}^{n_{trees}} \sum_{t \in T_i: v(t)=j} p(t) \cdot \Delta \text{impurity}(t)$$

2. **高共线性特征移除**：计算特征间相关性，移除相关系数超过0.95的高度共线特征。

3. **数据缩放**：采用稳健缩放（Robust Scaling）

   $$X_{scaled} = \frac{X - \text{median}(X)}{\text{IQR}(X)}$$

### 4.2 模型构建与评估

#### 4.2.1 预测模型构建

PM2.5浓度预测可建立如下数学模型：

$$PM_{2.5}(t) = f(\mathbf{X}(t), \mathbf{X}(t-1), \mathbf{X}(t-2), ..., \mathbf{X}(t-p)) + \varepsilon(t)$$

其中，$PM_{2.5}(t)$ 表示 $t$ 时刻的PM2.5浓度，$\mathbf{X}(t)$ 表示 $t$ 时刻的特征向量，$p$ 表示滞后阶数，$f(\cdot)$ 为预测函数，$\varepsilon(t)$ 为随机误差。

尝试了多种回归模型：

1. **线性回归模型**：
   $$ \hat{y} = \beta_0 + \sum_{j=1}^{p} \beta_j X_j $$

2. **树集成模型**（以梯度提升树为例）：
   $$ F_m(x) = F_{m-1}(x) + \gamma_m h_m(x) $$
   
   其中，$F_m(x)$ 为第 $m$ 次迭代的预测值，$h_m(x)$ 为第 $m$ 棵树，$\gamma_m$ 为步长。

3. **XGBoost模型**：目标函数为
   $$ \text{Obj} = \sum_{i=1}^{n} l(y_i, \hat{y}_i) + \sum_{k=1}^{K} \Omega(f_k) $$
   
   其中，$l$ 为损失函数，$\Omega$ 为正则化项：
   $$ \Omega(f) = \gamma T + \frac{1}{2}\lambda ||\omega||^2 $$

4. **LightGBM模型**：采用基于直方图的决策树算法，具有更高的训练效率。

#### 4.2.2 模型评估指标

使用以下指标评估模型性能：

1. **均方根误差(RMSE)**：
   $$ \text{RMSE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2} $$

2. **平均绝对误差(MAE)**：
   $$ \text{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i| $$

3. **平均绝对百分比误差(MAPE)**：
   $$ \text{MAPE} = \frac{1}{n}\sum_{i=1}^{n}\left|\frac{y_i - \hat{y}_i}{y_i}\right| \times 100\% $$

4. **决定系数(R²)**：
   $$ \text{R}^2 = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2} $$

### 4.4 模型改进策略

针对静稳天气下预测误差增大的问题，提出以下改进策略：

#### 4.4.1 专门化建模策略

基于状态分离的思想，为不同气象条件构建专门的预测模型：

$$ f_{hybrid}(\mathbf{X}) = \begin{cases}
f_{stagnant}(\mathbf{X}), & \text{if } \text{is\_stagnant} = 1 \\
f_{non\_stagnant}(\mathbf{X}), & \text{if } \text{is\_stagnant} = 0
\end{cases} $$

#### 4.4.2 集成学习改进

构建Stacking集成模型，结合多个基础学习器：

$$ f_{ensemble}(\mathbf{X}) = g\left( f_1(\mathbf{X}), f_2(\mathbf{X}), ..., f_m(\mathbf{X}) \right) $$

其中，$f_1, f_2, ..., f_m$ 为基础学习器，$g$ 为元学习器，使用Ridge回归避免过拟合。

#### 4.4.3 混合预测器设计

结合专门模型和集成模型的优势，设计动态加权混合预测器：

$$ f_{hybrid}(\mathbf{X}) = \begin{cases}
\alpha \cdot f_{stagnant}(\mathbf{X}) + (1-\alpha) \cdot f_{ensemble}(\mathbf{X}), & \text{if } \text{is\_stagnant} = 1 \\
\beta \cdot f_{non\_stagnant}(\mathbf{X}) + (1-\beta) \cdot f_{ensemble}(\mathbf{X}), & \text{if } \text{is\_stagnant} = 0
\end{cases} $$

应用改进策略后，模型在静稳天气条件下的性能提升如下：

| 评估指标 | 原始模型 | 改进模型 | 相对提升 |
|----------|----------|----------|----------|
| RMSE     | 19.39    | 17.12    | 11.7%    |
| MAE      | 11.73    | 10.28    | 12.4%    |
| R²       | 0.86     | 0.89     | 3.5%     |

改进后的模型在静稳天气条件下RMSE降低了11.7%，MAE降低了12.4%，R²提高了3.5%，表明专门化建模策略有效减小了静稳天气下的预测误差。

## 6. 结论与讨论

### 6.1 主要结论

本研究基于北京东四站点2013年3月至2017年2月的空气质量监测数据，开展了数据预处理与时空特征分析、PM2.5预测模型构建与性能分析、减排策略优化三个主要工作，得出以下主要结论：

1. **时空特征分析方面**：
   - PM2.5浓度呈现明显的季节性变化，冬季高于平均水平63%，夏季低于平均水平37%
   - 日内变化呈双峰模式，早晨和傍晚峰值分别高于日均值18%和25%
   - 风速是影响PM2.5最显著的气象因素，静稳天气下PM2.5浓度高于非静稳天气63.5%

2. **预测模型方面**：
   - LightGBM模型表现最佳，测试集RMSE为17.85μg/m³，R²为0.91
   - 静稳天气下预测误差绝对值有所增大，RMSE增加6.41%，MAE增加18.16%
   - 采用专门化建模策略后，静稳天气下的预测误差显著降低，RMSE降低11.7%

3. **减排策略方面**：
   - 在目标减排量为18.69μg/m³的情况下，最优策略为实施10小时洒水抑尘
   - 最优方案总成本30,000元，远低于预算上限100,000元
   - 从成本效益比看，洒水抑尘最经济（6.67μg/m³/万元），其次是工厂限产（6.25μg/m³/万元）和限行（6.00μg/m³/万元）

### 6.2 模型评价

#### 6.2.1 模型优点

1. **数据预处理全面**：采用多种方法处理缺失值和异常值，构建了丰富的特征变量，为后续建模奠定了坚实基础。

2. **模型选择多样**：尝试了多种回归模型，包括线性模型和非线性模型，从中选择了最优的LightGBM模型。

3. **针对静稳天气专门优化**：针对静稳天气条件下预测性能下降的问题，提出了专门化建模策略，有效提高了特殊条件下的预测准确性。

4. **减排策略优化合理**：通过整数规划模型求解最优减排策略，既满足减排目标又最小化成本，具有较强的实用性。

#### 6.2.2 模型局限性

1. **空间尺度限制**：研究仅基于单个监测站点数据，没有考虑空间分布和区域传输的影响，可能影响预测的空间适用性。

2. **时间尺度限制**：预测模型主要针对短期（如日尺度）预测，对于中长期预测可能存在局限性。

3. **线性叠加假设简化**：减排措施的效果假设为线性叠加，忽略了措施间可能存在的协同或拮抗效应。

4. **静态优化局限**：减排策略优化是静态的，没有考虑动态实施过程中的反馈调整机制。

### 6.3 改进方向

1. **空间维度扩展**：整合多站点数据，构建空间-时间模型，考虑污染物的区域传输和扩散过程。

2. **深度学习应用**：尝试LSTM、Transformer等深度学习方法，更好地捕捉时序数据的长期依赖关系。

3. **增强静稳天气特征**：引入边界层高度、大气稳定度等更专业的气象参数，提高静稳天气条件下的预测准确性。

4. **动态优化策略**：发展动态减排策略优化模型，根据实时监测和预测结果动态调整减排措施的实施力度和时长。

5. **考虑复合影响**：引入减排措施间的交互效应，构建非线性优化模型，更准确地评估综合减排效果。

"""

def fill_missing_values(df):
    """填充缺失值"""
    # 创建数据副本
    df_filled = df.copy()

        # 首先尝试线性插值

        # 对于仍然存在的缺失值，使用同时段历史均值填充

            df_filled['month_day_hour'] = df_filled.index.strftime('%m-%d-%H')
            monthly_hourly_mean = df_filled.groupby('month_day_hour')[col].transform('mean').round(3)
            df_filled[col] = df_filled[col].fillna(monthly_hourly_mean)
            df_filled.drop('month_day_hour', axis=1, inplace=True)
    
    # 2. 污染物数据: 使用相关性高的污染物线性回归预测
    pollution_cols = ['PM2.5', 'PM10', 'SO2', 'NO2', 'CO', 'O3']
    
    # 计算污染物之间的相关性
    correlation = df_filled[pollution_cols].corr()
    
    for col in pollution_cols:
        if df_filled[col].isnull().sum() > 0:
            # 找出与当前污染物相关性最高的其他污染物
            most_correlated = correlation[col].drop(col).abs().idxmax()
            
            # 使用非缺失值数据训练简单线性回归模型
            mask = ~df_filled[col].isnull() & ~df_filled[most_correlated].isnull()
            if mask.sum() > 0:
                # 简单线性回归填充
                slope, intercept, _, _, _ = stats.linregress(
                    df_filled.loc[mask, most_correlated],
                    df_filled.loc[mask, col]
                )
                # 预测缺失值
                missing_mask = df_filled[col].isnull() & ~df_filled[most_correlated].isnull()
                pred_values = slope * df_filled.loc[missing_mask, most_correlated] + intercept
                df_filled.loc[missing_mask, col] = pred_values.round(3)
    
    return df_filled

def feature_engineering(df):
    """特征工程"""
    # 创建特征工程后的数据副本
    df_featured = df.copy()
    
    # 1. 时间特征
    df_featured['hour_sin'] = np.sin(2 * np.pi * df_featured.index.hour / 24)
    df_featured['hour_cos'] = np.cos(2 * np.pi * df_featured.index.hour / 24)
    df_featured['day_sin'] = np.sin(2 * np.pi * df_featured.index.day / 31)
    df_featured['day_cos'] = np.cos(2 * np.pi * df_featured.index.day / 31)
    df_featured['month_sin'] = np.sin(2 * np.pi * df_featured.index.month / 12)
    df_featured['month_cos'] = np.cos(2 * np.pi * df_featured.index.month / 12)
    df_featured['is_weekend'] = df_featured.index.weekday >= 5
    
    # 2. 特征交互
    # 温度与风速交互 (风寒指数)
    df_featured['temp_wind'] = df_featured['TEMP'] * df_featured['WSPM']
    
    # 湿度与温度交互 (热指数)
    if 'HUMI' in df_featured.columns:
        df_featured['temp_humi'] = df_featured['TEMP'] * df_featured['HUMI'] / 100
    
    # 3. 滞后特征 (对PM2.5)
    for lag in [1, 3, 6, 12, 24]:
        df_featured[f'PM25_lag_{lag}'] = df_featured['PM2.5'].shift(lag)
    
    # 4. 大气稳定性指标 (简化版，基于温度和风速)
    df_featured['is_stagnant'] = ((df_featured['WSPM'] < 2) & (df_featured['TEMP'] > 20)).astype(int)
    
    return df_featured

def main():
    # 加载原始数据
    df = load_data("附件一.csv")
    
    # 填充缺失值
    df_filled = fill_missing_values(df)
    
    # 特征工程
    df_featured = feature_engineering(df_filled)
    
    # 保存处理后的数据
    df_featured.to_csv("processed_data.csv")

def get_base_models():
    """获取基础模型列表"""

        'LGB': lgb.LGBMRegressor(n_estimators=100, learning_rate=0.1, random_state=42),
        'XGB': xgb.XGBRegressor(n_estimators=100, learning_rate=0.1, random_state=42)
    }
    return models

def evaluate_model(y_true, y_pred, model_name):
    """评估模型性能"""
    # 计算评估指标
    rmse = np.sqrt(mean_squared_error(y_true, y_pred))
    mae = mean_absolute_error(y_true, y_pred)
    r2 = r2_score(y_true, y_pred)
    
    # 计算MAPE(平均绝对百分比误差)
    mape = np.mean(np.abs((y_true - y_pred) / (y_true + 1e-10))) * 100
    
    metrics = {
        'model': model_name,
        'RMSE': rmse,
        'MAE': mae,
        'MAPE': mape,
        'R2': r2
    }
    
    return metrics

def train_models(X_train, y_train, X_test, y_test, models=None, output_dir="./models"):
    """训练多个模型并评估性能"""
    # 确保输出目录存在
    os.makedirs(output_dir, exist_ok=True)
    
    # 如果没有指定模型，使用默认模型
    if models is None:
        models = get_base_models()
    
    results = []
    trained_models = {}
    
    # 遍历所有模型进行训练和评估
    for name, model in models.items():
        print(f"\n训练模型: {name}")
        
        # 训练模型
        model.fit(X_train, y_train)
        
        # 预测训练集和测试集
        train_pred = model.predict(X_train)
        test_pred = model.predict(X_test)
        
        # 评估训练集性能
        train_metrics = evaluate_model(y_train, train_pred, f"{name}_train")
        
        # 评估测试集性能
        test_metrics = evaluate_model(y_test, test_pred, f"{name}_test")
        
        # 保存结果
        results.append(train_metrics)
        results.append(test_metrics)
        
        # 保存模型
        trained_models[name] = model
        joblib.dump(model, f"{output_dir}/{name}_model.pkl")
        
        print(f"模型 {name} 训练完成")
        print(f"训练集 RMSE: {train_metrics['RMSE']:.2f}, MAE: {train_metrics['MAE']:.2f}, R2: {train_metrics['R2']:.2f}")
        print(f"测试集 RMSE: {test_metrics['RMSE']:.2f}, MAE: {test_metrics['MAE']:.2f}, R2: {test_metrics['R2']:.2f}")
    
    # 将结果转换为数据框
    results_df = pd.DataFrame(results)

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-

"""
问题三：PM2.5减排策略优化 - 减排策略优化模块
构建线性规划模型，求解最优减排策略
"""

import os
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from pulp import LpMinimize, LpProblem, LpVariable, LpInteger, LpStatus, value

# 定义减排措施参数
MEASURES = {
    '限行': {'cost': 5000, 'efficiency': 3, 'color': 'skyblue'},
    '工厂限产': {'cost': 8000, 'efficiency': 5, 'color': 'lightgreen'},
    '洒水抑尘': {'cost': 3000, 'efficiency': 2, 'color': 'lightsalmon'}
}

def build_emission_reduction_model(target_reduction, total_budget=100000, max_hours=16):
    """构建减排优化模型"""
    # 创建问题实例
    problem = LpProblem("PM25_Emission_Reduction", LpMinimize)
    
    # 创建决策变量：每种措施实施的小时数
    variables = {
        measure: LpVariable(f"hours_{measure}", 0, max_hours, LpInteger)
        for measure in MEASURES
    }
    
    # 目标函数：最小化总成本
    problem += sum(MEASURES[measure]['cost'] * variables[measure] for measure in MEASURES), "总成本"
    
    # 约束条件1：减排效果达到目标
    problem += sum(MEASURES[measure]['efficiency'] * variables[measure] for measure in MEASURES) >= target_reduction, "减排效果约束"
    
    # 约束条件2：总成本不超过预算
    problem += sum(MEASURES[measure]['cost'] * variables[measure] for measure in MEASURES) <= total_budget, "预算约束"
    
    # 约束条件3：每种措施实施时间不超过最大时长
    for measure in MEASURES:
        problem += variables[measure] <= max_hours, f"{measure}时长约束"
    
    return problem, variables

def solve_emission_reduction_model(problem, variables):
    """求解减排优化模型"""
    # 求解问题
    problem.solve()
    
    # 检查求解状态
    print(f"优化模型求解状态: {LpStatus[problem.status]}")
    if LpStatus[problem.status] != "Optimal":
        raise Exception(f"模型求解未找到最优解，状态：{LpStatus[problem.status]}")
    
    # 整理结果
    solution = {measure: int(value(variables[measure])) for measure in variables}
    total_cost = sum(MEASURES[measure]['cost'] * solution[measure] for measure in solution)
    total_reduction = sum(MEASURES[measure]['efficiency'] * solution[measure] for measure in solution)
    
    # 计算实施时段
    implementation_periods = {}
    for measure in solution:
        if solution[measure] > 0:
            start_hour = 6
            end_hour = start_hour + solution[measure]
            implementation_periods[measure] = f"{start_hour:02d}:00-{end_hour:02d}:00"
    
    results = {
        'solution': solution,
        'total_cost': total_cost,
        'total_reduction': total_reduction,
        'implementation_periods': implementation_periods
    }
    
    return results

def main():
    # 加载PM2.5浓度数据并计算超标量
    daily_avg_pm25 = 120  # 假设当日PM2.5浓度为120μg/m³
    standard_value = 75   # 国家标准是75μg/m³
    target_reduction = daily_avg_pm25 - standard_value
    
    print(f"当日PM2.5平均浓度: {daily_avg_pm25} μg/m³")
    print(f"超标量: {target_reduction} μg/m³")
    
    # 构建并求解优化模型
    problem, variables = build_emission_reduction_model(target_reduction)
    results = solve_emission_reduction_model(problem, variables)
    
    # 输出结果
    print("\n=== 最优减排策略 ===")
    for measure, hours in results['solution'].items():
        if hours > 0:
            period = results['implementation_periods'][measure]
            cost = MEASURES[measure]['cost'] * hours
            reduction = MEASURES[measure]['efficiency'] * hours
            print(f"{measure}: {hours}小时 ({period}), 成本: {cost}元, 减排效果: {reduction} μg/m³")
    
    print(f"\n总成本: {results['total_cost']}元")
    print(f"总减排效果: {results['total_reduction']} μg/m³")
