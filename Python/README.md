# 空气质量数据预处理与分析

本项目包含对北京东四站点空气质量数据的预处理和可视化分析代码，用于解决"基于空气质量数据的预测与减排策略优化"问题中的问题一。

## 文件说明

- `data_preprocessing.py`: 数据预处理脚本，包括缺失值处理、异常值检测、特征工程等
- `data_visualization.py`: 数据可视化脚本，用于分析数据的时空特征
- `run.py`: 主运行脚本，自动执行完整数据处理与分析流程

## 运行环境要求

- Python 3.6+
- pandas
- numpy
- matplotlib
- seaborn
- scipy

可以通过以下命令安装所需依赖：

```bash
pip install pandas numpy matplotlib seaborn scipy
```

## 使用方法

### 推荐方法：使用主运行脚本

```bash
python run.py
```

此脚本会依次执行：
1. 检查输入文件和创建输出目录
2. 运行数据预处理
3. 运行数据可视化分析
4. 在控制台显示进度和结果总结

### 单独运行预处理脚本

```bash
python data_preprocessing.py
```

此脚本会读取`../附件一.csv`文件，并进行以下处理：

- 数据加载与基本信息查看
- 缺失值检测与填充
- 异常值检测与处理
- 特征工程（时间特征、风向处理、静稳天气标记等）
- 保存处理后的数据至`../processed/processed_data.csv`

### 单独运行数据可视化分析

```bash
python data_visualization.py
```

此脚本使用预处理后的数据，生成以下可视化结果：

- 污染物时间序列图（日均值、月均值）
- 相关性热力图（污染物间、污染物与气象因子间）
- 污染物日内变化模式
- 污染物季节性变化特征
- 风玫瑰图
- PM2.5与气象因素关系图
- 静稳天气与非静稳天气对比分析
- 小时-月份热力图
- 工作日与周末污染水平比较
- 季节性分析

所有图表将保存在`../processed/figures`目录下。

## 输出文件

运行完成后，将在项目根目录的`processed`文件夹下生成以下内容：

- `processed_data.csv`: 预处理后的数据文件
- `figures/`: 包含所有生成的可视化图表

## 预处理功能详解

### 缺失值处理

- 对气象数据采用线性插值
- 对长序列缺失使用同期历史数据填充
- 对污染物数据结合相关性最高的其他污染物进行线性回归预测

### 异常值处理

- 使用Z-Score或IQR方法检测异常值
- 支持多种处理策略：截断、均值替换、中位数替换

### 特征工程

- 时间特征：周期性编码、季节标记、供暖期标记等
- 风向处理：风向文本转角度、角度的周期性编码
- 静稳天气特征：标记风速<1m/s的静稳天气及其持续时长
- 污染物比值特征：如PM2.5/PM10比值
- 空气质量等级：基于国家标准划分

## 可视化分析内容

通过可视化分析，可以直观了解：

1. 污染物的长期趋势和季节性变化
2. 不同污染物间的相关关系
3. 气象因素对污染物浓度的影响
4. 静稳天气条件下的污染特征
5. 工作日与周末的污染差异
6. 小时尺度的污染物变化模式
