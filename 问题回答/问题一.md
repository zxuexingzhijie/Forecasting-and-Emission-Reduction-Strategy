# 问题一：数据预处理与时空特征分析

## 1. 数据概述

本研究使用北京东四站点2013年3月1日至2017年2月28日期间的空气质量监测数据，包含空气质量参数（PM2.5、PM10、SO₂、NO₂、CO、O₃）和气象参数（温度、气压、露点温度、降水、风向、风速）。数据维度包括时间（年、月、日、小时）和空间（监测站点）。

数据基本情况：
- 时间跨度：4年（2013.03-2017.02）
- 时间粒度：小时级
- 预期记录数：$4×365×24=35040$ 条（实际可能存在缺失）
- 变量数量：18个（时间维度4个，污染物指标6个，气象指标6个，站点标识1个，序号1个）

## 2. 数据预处理

### 2.1 缺失值分析与处理

|------|------------|---------------|

| PM10 | 5203 | 14.85 |

| NO2 | 4316 | 12.32 |
| CO | 4253 | 12.14 |
| O3 | 4429 | 12.64 |

| DEWP | 3772 | 10.77 |

#### 2.1.2 缺失值填充方法

针对不同类型的变量，采用了不同的缺失值填充策略：

1. **气象数据填充**：
   - 短期缺失采用线性插值：
   
   $$y_t = y_{t-1} + \frac{y_{t+k} - y_{t-1}}{k}(t - (t-1))$$
   
   其中，$y_t$表示缺失的时间点$t$处的值，$y_{t-1}$和$y_{t+k}$分别表示缺失时间点前后最近的非缺失值。
   
   - 长期缺失（超过24小时）采用同时段历史均值：
   
   $$y_{missing}(m,d,h) = \frac{1}{n} \sum_{year} y(year,m,d,h)$$
   
   其中，$(m,d,h)$表示月-日-小时的时间组合，$n$为历史同时段有效观测数。

2. **污染物数据填充**：
   - 利用相关性最高的其他污染物进行线性回归预测：
   
   $$y_{missing} = \alpha \times x_{correlated} + \beta$$
   
   其中，$\alpha$和$\beta$是从非缺失数据中通过最小二乘法确定的线性回归系数：
   
   $$\alpha = \frac{\sum_{i=1}^{n}(x_i-\bar{x})(y_i-\bar{y})}{\sum_{i=1}^{n}(x_i-\bar{x})^2}$$
   
   $$\beta = \bar{y} - \alpha \bar{x}$$
   
   - 对仍然存在的缺失值，采用线性插值和同时段历史均值填充。

3. **风向处理**：
   - 风向是循环性变量，先将风向文本转换为角度值：
   
   $$\theta_{direction} = \text{map}(direction)$$
   
   - 采用角度插值，避免跨越0°/360°边界的问题：
   
   $$\theta_{missing} = \theta_{t-1} + \frac{\min(|\theta_{t+k} - \theta_{t-1}|, 360 - |\theta_{t+k} - \theta_{t-1}|)}{k} \times \text{sign}$$
   
   其中，$\text{sign}$确定插值方向（顺时针或逆时针），选择角度最小的方向。

### 2.2 异常值检测与处理

#### 2.2.1 异常值检测方法

采用两种主要方法检测异常值：

1. **基于Z-score的检测**：  
   将偏离均值超过$n$个标准差的值视为异常值：
   
   $$z_i = \frac{x_i - \mu}{\sigma}$$
   
   其中，$\mu$和$\sigma$分别为均值和标准差，当$|z_i| > 3$时判定$x_i$为异常值。

2. **基于IQR的检测**：  
   将超出四分位距离$n$倍的值视为异常值：
   
   $$lower\_bound = Q_1 - n \times IQR$$
   $$upper\_bound = Q_3 + n \times IQR$$
   
   其中，$Q_1$和$Q_3$分别为第一和第三四分位数，$IQR = Q_3 - Q_1$为四分位距，$n$通常取1.5。

#### 2.2.2 异常值处理策略

对检测到的异常值，使用以下策略进行处理：

1. **截断法(Capping)**：
   将异常值限制在合理范围内：
   
   $$x_i' = \begin{cases}
   lower\_bound, & x_i < lower\_bound \\
   x_i, & lower\_bound \leq x_i \leq upper\_bound \\
   upper\_bound, & x_i > upper\_bound
   \end{cases}$$

2. **均值/中位数替换**：
   对极端异常值，直接用均值或中位数替换：
   
   $$x_i' = \begin{cases}
   \mu, & |z_i| > 3 \quad \text{(均值替换)}\\
   \text{median}(X), & |z_i| > 3 \quad \text{(中位数替换)}
   \end{cases}$$

通过异常值处理，确保数据在合理范围内，避免极端值对后续分析的不利影响。

### 2.3 特征工程

为增强数据的表达能力，构建了以下新特征：

1. **时间特征提取**：
   - 星期几：$day\_of\_week \in \{0,1,2,3,4,5,6\}$
   - 周末标记：$is\_weekend = \mathbb{1}_{day\_of\_week \in \{5,6\}}$
   - 季节：$season = \lfloor\frac{(month \mod 12) + 3}{3}\rfloor$
   - 供暖期标记：$is\_heating\_period = \mathbb{1}_{(month \geq 11) \lor (month \leq 3) \land \neg((month = 11 \land day < 15) \lor (month = 3 \land day > 15))}$

2. **周期性特征变换**：使用三角函数变换捕捉时间的周期性
   - 小时周期性：$hour\_sin = \sin(2\pi \times \frac{hour}{24})$，$hour\_cos = \cos(2\pi \times \frac{hour}{24})$
   - 月份周期性：$month\_sin = \sin(2\pi \times \frac{month}{12})$，$month\_cos = \cos(2\pi \times \frac{month}{12})$
   - 风向周期性：$wd\_sin = \sin(\frac{\pi}{180} \times wd\_angle)$，$wd\_cos = \cos(\frac{\pi}{180} \times wd\_angle)$

3. **特殊气象特征**：
   - 静稳天气标记：$is\_stagnant = \mathbb{1}_{WSPM < 1.0}$
   - 静稳持续时间：记录静稳天气持续的小时数
   - 极端温度标记：$is\_extreme\_cold = \mathbb{1}_{TEMP < Q_1}$，$is\_extreme\_hot = \mathbb{1}_{TEMP > Q_3}$

4. **污染物比值特征**：
   - PM比值：$PM\_ratio = \frac{PM2.5}{PM10}$（反映细颗粒物在可吸入颗粒物中的占比）

5. **空气质量等级分类**：根据PM2.5浓度设定空气质量等级
   - 优：0-35 μg/m³
   - 良：36-75 μg/m³
   - 轻度污染：76-115 μg/m³
   - 中度污染：116-150 μg/m³
   - 重度污染：151-250 μg/m³
   - 严重污染：>250 μg/m³

## 3. 时空特征分析

### 3.1 时间序列特征分析

#### 3.1.1 长期趋势分析

通过对2013年3月至2017年2月期间PM2.5的月均浓度分析，发现：

1. **年际变化**：PM2.5逐年下降趋势明显，这可归因于北京市2013年启动的《大气污染防治行动计划》的实施效果。2013年年均浓度约为89.5 μg/m³，到2016年下降至约58 μg/m³，降幅约35%。

2. **季节性变化**：污染物浓度呈现明显的季节性周期，冬季（11-2月）浓度显著高于其他季节，夏季（6-8月）浓度最低。可通过季节分解模型表示：
   
   $$Y_t = T_t + S_t + \varepsilon_t$$
   
   其中，$Y_t$为原始时间序列，$T_t$为长期趋势分量，$S_t$为季节性分量，$\varepsilon_t$为随机波动分量。

   季节性指数均值结果：
   - 冬季（12、1、2月）：1.63（高于平均水平63%）
   - 春季（3、4、5月）：0.94
   - 夏季（6、7、8月）：0.63（低于平均水平37%）
   - 秋季（9、10、11月）：0.80

#### 3.1.2 日内变化模式

PM2.5浓度在一天内呈现双峰模式：

1. **早晨峰值**（7:00-9:00）：平均浓度比日均值高约18%，与早高峰交通排放和边界层高度变化有关。

2. **午间低谷**（13:00-16:00）：平均浓度比日均值低约15%，受边界层充分发展和太阳辐射增强影响。

3. **傍晚峰值**（19:00-22:00）：平均浓度比日均值高约25%，是全天最高峰值，与晚高峰交通排放和边界层高度下降有关。

4. **日内模式的季节差异**：冬季日内波动幅度明显小于夏季，可用熵值量化：
   
   $$H_{季节} = -\sum_{t=0}^{23} p_t \log p_t$$
   
   其中，$p_t = \frac{PM2.5_t}{\sum_{i=0}^{23} PM2.5_i}$表示某小时浓度占全天总浓度的比例。

   熵值结果：冬季为2.94，夏季为2.71，表明夏季日内分布更不均匀（波动更大）。

#### 3.1.3 周变化模式

工作日与周末的PM2.5水平存在差异，但差异不如季节因素显著。统计检验结果：

- 工作日平均：72.8 μg/m³
- 周末平均：69.4 μg/m³
- 差异率：-4.7%
- t检验p值：0.037（显著性水平α=0.05下差异显著）

这种差异反映了周末工业和交通活动减少对空气质量的影响。

### 3.2 气象因素与PM2.5关系分析

#### 3.2.1 相关性分析

通过相关分析，量化了气象因素与PM2.5浓度的关系：

| 气象因素 | 相关系数 | p值 |
|----------|----------|-----|
| 风速(WSPM) | -0.397 | <0.001 |
| 温度(TEMP) | -0.281 | <0.001 |
| 气压(PRES) | 0.234 | <0.001 |
| 露点温度(DEWP) | 0.113 | <0.001 |
| 降水(RAIN) | -0.087 | <0.001 |

可见，风速是影响PM2.5最显著的气象因素，相关系数为-0.397，表明风速越大，PM2.5浓度越低，这符合污染物扩散理论。

#### 3.2.2 静稳天气与PM2.5的关系

静稳天气（风速<1m/s）对PM2.5有显著影响。对比分析：

- 静稳天气条件下平均PM2.5：104.3 μg/m³
- 非静稳天气条件下平均PM2.5：63.8 μg/m³
- 增幅：63.5%
- Mann-Whitney U检验p值：<0.001（差异极显著）

这种显著差异反映了静稳天气限制了污染物的水平和垂直扩散，导致污染物积累。

#### 3.2.3 风向对PM2.5的影响

通过绘制污染玫瑰图，分析了不同风向下的PM2.5浓度水平。结果显示：

1. **高污染风向**：
   - 南风(S)：平均PM2.5为97.2 μg/m³
   - 东南风(SE)：平均PM2.5为89.5 μg/m³
   - 西南风(SW)：平均PM2.5为85.6 μg/m³

2. **低污染风向**：
   - 西北风(NW)：平均PM2.5为48.3 μg/m³
   - 北风(N)：平均PM2.5为52.1 μg/m³
   - 东北风(NE)：平均PM2.5为55.7 μg/m³

这一分布与北京市周边地区的产业布局和地形特征相关，南部和东部为工业密集区，而北部和西北部为山区，污染源较少。

#### 3.2.4 复合气象条件分析

构建气象条件组合矩阵，分析多重气象条件下的PM2.5水平：

$$PM2.5_{avg} = f(wind\_speed\_class, temperature\_class, rain\_class)$$

结果显示，最不利气象组合（静稳天气+低温+无降水）下的PM2.5浓度平均达到138.6 μg/m³，是最有利气象组合（高风速+高温+有降水）下浓度（26.7 μg/m³）的5.19倍。

### 3.3 多污染物协同分析

#### 3.3.1 污染物间相关性

污染物之间存在复杂的相关关系，反映了它们的共同来源和化学转化过程：

| 污染物对 | 相关系数 | 化学机制解释 |
|----------|----------|--------------|
| PM2.5-PM10 | 0.893 | PM2.5是PM10的子集，共同受一次排放与二次转化影响 |
| PM2.5-NO2 | 0.697 | NO2是二次PM2.5形成的重要前体物 |
| PM2.5-CO | 0.712 | 指示共同的燃烧源（如交通、燃煤） |
| PM2.5-SO2 | 0.567 | SO2是硫酸盐（PM2.5组分）的前体物 |
| PM2.5-O3 | -0.351 | 负相关性反映了光化学过程的季节性差异 |

这些相关关系可用于污染来源解析和预测模型构建。

#### 3.3.2 PM2.5/PM10比值分析

PM2.5/PM10比值是重要的大气污染特征指标，反映了细颗粒物在可吸入颗粒物中的占比。该比值的变化规律：

1. **季节性变化**：
   - 冬季：0.78（最高）
   - 春季：0.62
   - 夏季：0.65
   - 秋季：0.71

2. **日内变化**：
   - 凌晨至早晨（0:00-8:00）：0.72
   - 白天（9:00-16:00）：0.65（最低）
   - 傍晚至夜间（17:00-23:00）：0.74（次高）

高比值表明细颗粒物占比大，通常与二次转化和燃烧源（如燃煤取暖）关系密切；低比值则与自然源（如扬尘）和机械研磨过程关系更大。

## 4. 结论与发现

通过对北京东四站点空气质量数据的预处理与时空特征分析，得出以下主要结论：

1. **时间模式**：
   - PM2.5浓度呈现明显的年际下降趋势，反映了减排政策的有效性
   - 存在显著的季节变化，冬季污染最严重，夏季最轻
   - 日内双峰模式（早晚高、午间低）反映了人类活动和气象因素的复合影响

2. **气象影响**：
   - 风速是影响PM2.5浓度最显著的气象因素，静稳天气极易导致重污染
   - 风向对污染水平有明显影响，南风和东南风下污染程度高
   - 气温与PM2.5呈负相关，低温条件更易形成高浓度污染

3. **污染物关联**：
   - PM2.5与PM10、NO2、CO高度相关，表明它们有共同的排放源
   - PM2.5/PM10比值的变化揭示了不同季节和时段污染物的组成特征

这些发现为构建预测模型和制定针对性减排策略提供了科学依据。特别地，静稳天气条件下，气象扩散条件受限，应当采取更严格的临时减排措施；同时，在冬季供暖期和交通高峰期，应当重点管控相关排放源。
