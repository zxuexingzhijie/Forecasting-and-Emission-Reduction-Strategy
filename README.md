# 空气质量预测与减排策略优化

本项目通过分析北京市空气质量数据，建立了空气污染物（PM2.5）浓度的预测模型，并设计了经济有效的减排方案。

## 项目内容

- **数据分析**：分析了北京市东四监测站多年的空气质量数据，发现了污染物浓度的季节变化规律和日内变化特点
  - 数据来源：2013-2017年北京东四监测站的小时级监测数据
  - 分析内容：污染物浓度的季节变化、日变化规律以及与气象因素的关系
  
- **预测模型**：使用机器学习方法预测未来的空气污染物浓度，特别关注了低风速天气下的预测准确性
  - 使用多种机器学习算法（线性回归、随机森林、XGBoost、LightGBM等）
  - 通过特征工程提高模型性能，包括时间特征、滞后特征和气象交互特征
  
- **减排优化**：设计了限行、工厂限产和洒水抑尘等减排措施的最佳组合方案，平衡了减排效果和经济成本
  - 使用整数规划模型优化减排组合
  - 分析不同措施的成本效益比

## 主要成果

- 建立了准确度超过90%的PM2.5预测模型
- 设计了经济高效的减排策略，以最低成本达到空气质量改善目标
- 为城市空气质量管理提供了数据支持和决策参考
